# Changelog

All notable changes to FormaDS are documented in this file.

The project follows [Semantic Versioning](https://semver.org/). No stable release
has been published yet.

## [Unreleased]

### Added

- Reusable SwiftUI foundations, semantic tokens and components for iOS 17+.
- Aurora, Horizon and Midnight Gold themes with Light and Dark appearances.
- English and European Portuguese package-owned localized defaults.
- FormaDSShowcase galleries for themes, foundations and components.
- Accessibility support for VoiceOver, Dynamic Type, Reduce Motion and touch targets.
- Automated package tests and a GitHub Actions validation workflow.
- Public API, architecture, theming, localization, testing and integration documentation.

### Changed

- Audited the architecture and public API for consistency and consumer independence.
- Hardened progress, chart and feedback behavior against regression.
- Made the CI configuration resilient to Xcode 27 patch and simulator-runtime updates.

### Release notes

- The independent-consumer validation, final accessibility sign-off and release-owner
  approval remain required before `1.0.0`.
- No migration from a stable version is required because no stable release exists.
